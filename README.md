# E-Commerce Shopping Application

This is a full-stack E-Commerce Shopping Application built with the MERN stack (MongoDB, Express.js, React.js, Node.js).

## Project Structure

-   `backend/`: Contains the Node.js/Express.js API server.
-   `frontend/`: Contains the React.js client application.

## Getting Started

Follow the instructions below to set up and run the project locally.

### 1. Backend Setup

Navigate to the `backend/` directory and follow its `README.md` for setup instructions.

### 2. Frontend Setup

Navigate to the `frontend/` directory and follow its `README.md` for setup instructions.

## Features (Initial Scaffold)

### Backend:
-   User Authentication (Registration, Login using JWT)
-   Product Listing and Details
-   MongoDB integration
-   Modular API structure (models, controllers, routes, middleware)

### Frontend:
-   User Registration and Login forms
-   Display products on home screen
-   Client-side routing
-   Context API for authentication state management
-   Basic UI components (Header, Footer)
